# 暂未使用的设计素材

这两个文件原本放在 `src/static/` 下，但**全项目没有任何代码引用它们**。
而 uni-app 会把 `src/static/` **整目录原样复制**进小程序包，
未引用的图片同样计入主包体积，所以把它们移到了这里。

| 文件 | 尺寸 | 分析结果 | 推测用途 |
|---|---|---|---|
| `Configuration.png` | 200×200 RGBA，11,121 字节 | 73.9% 完全透明，主色 `#ff895d` 占 23.4% | 橙色线稿图标，看名字应是「设置 / 配置」齿轮类 |
| `globle.png` | 200×200 RGBA，14,766 字节 | 41.2% 透明，主色 `#ffda64`（金黄 35.1%）+ `#3a394b`（深藏青 15.4%）+ 白 | 卡通地球 / 星球插画 |

## 为什么要移出来

- 实测主包 **521,418 → 510,297 字节（−11,121）**，这正是 `Configuration.png` 的大小
  （它已经在上一版产物里了）
- `globle.png` 是刚加进来的，还没赶上构建；不移出的话下一次构建它会再占 **14,766 字节**，
  现在一并避免了。两个文件合计避免约 **25,887 字节**进包
- 判断依据：`src/static/**` 是 uni-app 约定的静态资源目录，构建时整目录复制，
  不会做引用分析；放在 `src/static/` 之外的目录则只有被 `import` 或引用时才会进包

## 以后要用怎么办

1. 放回 `src/static/` 下（建议按用途分目录，例如 `src/static/home/`、`src/static/globles/`）
2. 在代码里引用，路径以 `/static/...` 开头，例如 `src="/static/home/xxx.png"`
3. **文件名不要带空格或中文**：微信会校验 tabBar 图标等资源，
   文件名里多一个空格就会导致该图标（tabBar 场景下是全部图标）不渲染
