> 本材料聚焦**作品开发过程中**使用 AI 的情况；作品运行期调用大模型的能力（画像解析/问答）属于产品功能，已在主说明中另行说明，本材料不重复。

## 一、开发过程 AI 使用概述

| 项目 | 内容 |
|---|---|
| 使用工具 | 对话式 **AI 编程助手（基于 DeepSeek 大模型）** |
| 使用环节 | 编码实现辅助、问题定位与调试、构建验证、文档撰写草稿 |
| 人工承担 | 需求与方案设计、算法与计分规则、代码审查、开发者工具实测验证、最终决策 |
| 使用原则 | AI 只作为效率工具；所有产出经人工审查与实测后才会进入最终代码；不提交完整对话记录 |

使用场景举例（均来自本作品真实开发过程）：

1. 用 AI 辅助生成前端页面逻辑与接口封装（能力画像、人岗匹配、知识库、AI 助手等页面）；
2. 用 AI 协助定位与修复运行问题（详见第二节 Prompt 节选）；
3. 用 AI 协助重新实现图表（用原生 canvas 替换体积过大的图表库）；
4. 用 AI 起草说明文档、测试用例等文字材料的初稿，再由团队核对事实、修改定稿。

## 二、代表性开发 Prompt 节选（脱敏，完整对话不提交）

以下仅为能说明 AI 辅助方式的关键提示词**节选**，每条均附"AI 的作用"与"人工处理"。

### Prompt 1：实现"能力星球图"（AI 辅助编码）

> 请用小程序原生 canvas 2d 绘制能力雷达图：十维多边形 + 10 个顶点星球，
> 星球直径随分值变化、三档渐变配色，点击星球可查看得分；不要使用第三方图表库。

- **AI 作用**：给出绘制思路与初版代码（网格、多边形、渐变星球、触摸命中检测）；
- **人工处理**：团队确定视觉参数（颜色、尺寸、间距）、逐段审查代码、在开发者工具中运行验证并调整。

### Prompt 2：登录报错排查（AI 辅助调试）

> 小程序点击登录报错：`ReferenceError: baseURL is not defined`，请分析原因并给出修复方式。

- **AI 作用**：定位到"统一接口基址后部分页面遗漏导入"，列出受影响的文件；
- **人工处理**：团队逐一补齐导入、全仓扫描确认无遗漏、编译后实测登录通过。

### Prompt 3：图片大面积不显示排查（AI 辅助调试）

> 小程序大量图标不显示，部分图片地址形如 `https://youupro.xyz/noteshttps://youupro.xyz/ly/static/...`，
> 请分析原因并给出修复方案。

- **AI 作用**：指出"地址被重复拼接域名"的问题，并建议对每个图片地址做真实内容校验（HTTP 200 但返回 HTML 占位页的情况）；
- **人工处理**：团队修复地址、逐条校验可用性、按需恢复本地素材、重新构建验证。

### Prompt 4：富文本代码块渲染异常（AI 辅助调试）

> 文章详情页代码块显示异常，部分内容丢失。当前用 `<rich-text>` 渲染 Markdown 转换后的 HTML，
> 请分析可能原因。

- **AI 作用**：指出微信 `<rich-text>` 不支持 `<pre>` 标签，建议改为 `<div>` 并保留 `white-space: pre-wrap`；
- **人工处理**：团队在三个页面统一增加标签适配，并对代码块、表格等内容分别验证。

### Prompt 5：人岗匹配度显示 100% 的算法修复（AI 辅助定位，人工定规则）

> 某岗位只解析出 1 项可评估要求且学生满足该项，页面却显示匹配度 100%。请分析匹配引擎的归一化逻辑。

- **AI 作用**：定位到"参与归一化的维度过少"；给出排查路径；
- **人工处理**：团队复核后确定规则——可评估维度不足时按信息完整度封顶（1 项 → 37%），并在界面提示"信息不足"；补充测试用例并回归验证。

### Prompt 6：文档材料初稿（AI 辅助写作）

> 根据本作品实际情况，起草参赛用《测试用例记录》《运行与使用说明》的初稿，
> 按功能模块组织用例，并如实标注环境不具备的项。

- **AI 作用**：生成结构化初稿（用例表、章节结构）；
- **人工处理**：团队逐条核对功能真实性、补充实测结果、修正统计数字与表述。

## 四、AI 辅助的边界与核验声明

1. **决策与规则由团队确定**：产品需求、匹配算法与计分口径、界面方案由团队成员设计，AI 仅辅助实现与排查；
2. **AI 产出经人工审查与实测**：所有 AI 生成的代码均逐段审查，并在微信开发者工具中运行验证后才合入；
3. **如实描述**：本材料中的 Prompt 为节选，不虚构使用过程；AI 未直接生成最终交付的图片、音视频素材；
4. **不提交完整对话记录**：按要求仅提供必要的 Prompt 节选与截图作为辅助材料。
