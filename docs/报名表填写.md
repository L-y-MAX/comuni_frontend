## 3. 作品简介

作品为「职引星途」，一款面向高校毕业生的 AI 生涯规划与人岗匹配微信小程序，主题是让求职从凭感觉变成有依据。主要功能围绕一条主线展开：岗位能力画像把招聘原文拆解为十个维度的要求并列出具体技能与证书；学生能力画像把学生填写的技能、证书、项目与实习经历量化为同一套十维得分；人岗智能匹配逐项比对，输出匹配度、四类目得分、十维达成度、技能证书缺口与提升建议；个性化生涯发展报告据此生成职业目标、晋升路径与分阶段成长计划。此外提供校招岗位浏览、就业政策与校招资源离线库、知识库与 AI 助手问答。

创新特点有三：一是可解释的匹配，岗位与学生共用同一套十维基准，每个数字都有依据，并通过未提要求不计分、核心技能门槛、信息不足封顶三道规则防止匹配度误导；二是离线政策资源库只给来源与官方链接，不转载原文，兼顾时效与合规；三是针对小程序环境自研零依赖富文本渲染与异步 AI 任务链路，保证真机可用、页面不阻塞。应用价值：可低成本部署到高校就业中心或学院，学生打开即用，画像与匹配体系与具体数据源解耦，便于迁移到不同学校与行业。

## 4. 创意来源

选题背景：大学生求职普遍存在信息不对称。招聘信息混着专业、证书、素质、经验等十几个方面的要求，学生读不懂也拆不出"该补什么"；学生对自己强在哪、弱在哪往往只有模糊感觉，只能海投；现有招聘平台功能臃肿、广告与中介信息混杂，匹配结果多为黑盒，只给一个数字、不给依据；政策与校招信息分散且时效性强，学生查证成本高。

创作动机：做课程项目时和同学交流发现，大家求职主要在"猜"——猜岗位要什么、猜自己差在哪、猜该先学什么。我们希望把这种"猜"变成可量化、可解释、可执行的判断，于是把产品定位为求职辅导工具而不是流量平台。

核心创意：第一，用同一套十维能力框架作为"同一把尺子"，把岗位要求与学生能力放进同一坐标系，使匹配结果可解释、可相互对照；第二，匹配不仅要给结论，还要给依据、缺口和下一步行动，把"投不投"变成"补什么、怎么补"；第三，诚实处理数据的不确定性——招聘原文没写的要求不参与打分，信息不足时主动降级并明确告知，宁可说"信息不足"也不给误导性的高分。

## 5. 运行环境

软件环境：客户端为微信小程序，运行于微信 8.x 及以上版本（开发调试基础库 3.17.4），无需安装，搜索或扫码进入。服务端使用 Python 3.12、Django 5.2、Django REST Framework 开发接口，Celery 搭配 Redis 处理异步任务（画像解析与 AI 问答），数据库使用 PostgreSQL 18。前端采用 uni-app 3.0（Vue 3 + TypeScript + Vite）跨端编译，构建依赖 Node.js 18+ 与 pnpm。AI 能力调用 DeepSeek 大模型（OpenAI 兼容接口），需配置 API Key。

硬件环境：用户端为任意可运行微信的安卓或 iOS 智能手机；服务器建议 2 核 4G 起步（推荐 4 核 8G，需常驻 Web 服务、Celery Worker 与 Redis）；开发机为普通 PC 即可。

系统平台：服务端可部署于 Linux（本地开发使用 Windows，Celery 需以 --pool=solo 运行）；客户端运行于微信小程序平台。

必要配置：上线需可访问的 HTTPS 域名（小程序平台要求）、小程序 AppID 与 AppSecret、数据库连接参数、Redis 地址与 DeepSeek API Key。演示环境使用账号密码登录，微信一键登录接口已预留、待正式申请 AppID 后启用。本地联调时后端与 Redis、PostgreSQL 同机运行，前端通过微信开发者工具预览。
