# 职引星途 · 运行与使用说明

> 适用对象：评审专家、指导老师、体验成员。
> 说明对象：本作品的**当前版本**（参赛演示版）。文中所有操作均按当前版本的真实功能编写。

---

## 一、作品与版本说明（请先读）

本作品是微信小程序，**无需安装**，通过微信打开即可使用。但请注意一个关键事实：

> **官方小程序码对应的线上版本是最初的架构版本（早期演示版），后续迭代了大量功能，线上版本尚未更新。**
> 因此评审请以以下两种方式之一体验当前版本：
> 1. **现场演示 / 录屏**：由团队在开发者工具或真机上演示当前版本；
> 2. **体验版二维码**：由管理员在微信公众平台重新上传体验版后生成（见 2.2）。

当前版本与最初架构版本的主要差异包括：能力画像（AI 十维解析、星球图、徽章）、岗位能力画像、人岗匹配引擎、生涯发展报告、知识库、AI 助手、就业政策与校招资源库、我的收藏等均为后续新增；界面与交互也经过多轮重构。

## 二、运行条件与进入方式

### 2.1 运行条件

| 项目 | 要求 |
|---|---|
| 设备 | Android / iOS 智能手机；或电脑上的微信开发者工具（评审推荐） |
| 微信 | 微信 8.x 及以上；小程序基础库 3.17.x |
| 网络 | 需要联网访问后端接口与图片资源（本机演示时后端运行在开发电脑上） |
| 账号 | 使用提供的演示账号，或在小程序内注册新账号（账号密码登录） |
| 安装 | **无需安装**，扫码或搜索进入 |

### 2.2 三种进入方式（按推荐顺序）

**方式 A：开发者工具演示（评审现场推荐，功能最全、无网络依赖问题）**

1. 打开微信开发者工具（稳定版 2.02 及以上），选择「导入项目」；
2. 目录选择构建产物 `dist/build/mp-weixin`（由团队提供，或`npm run build:mp-weixin` 生成）；
3. AppID 使用项目自带的测试 AppID；
4. 导入后点击「编译」，在「详情 → 本地设置」中勾选 **不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书**；
5. 首页出现后即可按第 3 节流程操作。演示期间请保持开发机上后端服务运行（见 2.3）。

**方式 B：体验版（适合评委自行扫码体验）**

1. 管理员在微信公众平台「版本管理」上传当前构建包为**体验版**；
2. 「成员管理」把评委微信添加为**体验成员**；
3. 评委从体验成员身份扫码/打开体验版二维码，进入即当前版本；
4. 体验版需要后端接口可被公网访问，或由管理员在局域网内提供访问（见 2.3）。

**方式 C：正式版（当前不提供）**

正式版需要完成小程序发布、后端 HTTPS 部署与域名备案，目前尚未完成，故暂不提供正式版入口。

### 2.3 后端服务说明（真机/联调必需）

小程序依赖后端接口完成：登录、能力画像解析、岗位画像解析、人岗匹配、生涯报告、知识库、AI 问答等。后端由 Django + Celery + Redis 构成，**当前部署在开发机上**：

- 开发机启动后端后，接口地址为 `http://localhost:8000`；
- **开发者工具**与后端在同一台电脑，可直接访问；
- **真机**访问不到电脑的 localhost，需要将小程序接口基址改为开发机的局域网 IP（`http://192.168.x.x:8000`），并保证手机与电脑同一 Wi-Fi；或将后端部署到可公网访问的服务器（部署说明另附 `docs/deploy-guide.md`）；
- 后端未启动时：登录、画像生成、AI 问答等联网功能不可用；离线功能（就业政策与校招资源库检索）仍可查看。

## 三、登录方式

### 3.1 账号密码登录（当前可用）

1. 底部导航进入「我的」；
2. 点击「账号登录」；
3. 输入演示账号与密码（演示账号由团队随材料提供）→ 登录；
4. 也可在登录页进入注册，使用自己的账号注册后登录。

### 3.2 微信一键登录（暂未启用）

界面已预留微信一键登录入口，但正式启用需要小程序 AppID/AppSecret 正式资质，当前使用占位配置，**请使用账号密码登录**。

## 四、功能使用说明（按页面）

### 4.1 首页

- 搜索：搜索站内知识库、文档与用户（需登录）；未登录时仅展示本地资源检索结果；
- 四个快捷入口：**岗位招聘**、**就业政策与校招资源**、**岗位能力画像**、**知识库**；
- 输入搜索内容后快捷入口自动隐藏，点「✕ 退出搜索」恢复。

### 4.2 能力画像（核心功能）

1. 底部导航进入「能力画像」；
2. 按三组填写：基本信息（专业/年级/意向岗位/行业）、能力与证书（技能/证书）、经历补充（项目/实习/获奖/成绩/自我评价）；
3. 可点「填入示例」快速体验；
4. 点「生成画像」→ 等待 AI 解析（通常 3~10 秒）→ 得到十维得分、能力星球图、职业徽章墙、信息完整度、综合竞争力；
5. 「雷达星球 / 十维明细」可切换查看；点击星球可查看单项得分与说明。

### 4.3 岗位能力画像

路径：首页 →「岗位招聘」→ 选择岗位 → 查看岗位画像，或在首页点「岗位能力画像」直接进入选岗。
输出：十维要求强度、岗位技能与证书清单（区分必须/优先）、解析来源标注（大模型/规则）。原文未提及的维度标注「岗位未提要求」，不参与打分。

### 4.4 人岗智能匹配

路径：能力画像 → 查看岗位匹配（或从岗位画像发起）。
输出：综合匹配度与等级、四大类目得分、十维达成度、技能/证书缺口、关键短板与提升建议。
说明：岗位要求信息不足时会按信息完整度封顶并提示「信息不足」，避免误导性高分。

### 4.5 生涯发展报告

路径：能力画像 → 生涯发展报告。
内容：求职方向与匹配分析、目标与路径规划、分阶段成长计划（1~3 个月 / 4~12 个月 / 1 年以上）、评估与调整机制。支持任务勾选（本机保存）、复制/导出、历史报告回看。

### 4.6 知识库

- 新建知识库（名称 2~20 字，可选公开/私有），创建成功后进入文章列表；
- 新增/编辑文章：正文支持纯文本与 Markdown 混写，工具栏可加粗、斜体、下划线、调字号、标题、列表；右侧预览实时渲染；
- 列表显示每库文章数，支持最近更新/创建时间排序；更多菜单可重命名、设置权限、分享、删除；
- 每个知识库卡片上有「AI 提问」，可把整库内容带入 AI 助手提问；
- 首页搜索到的公开文档可一键复制到自己的知识库。

### 4.7 AI 助手

- 挂载文章（或知识库）作为上下文后提问；
- 回答以富文本形式呈现（标题、列表、代码块），可对照原文核对、复制、重新生成、停止生成；
- 回答可「存到知识库」保存为文章。

### 4.8 就业政策与校招资源

离线结构化资源库，分三个主题：就业政策、校招企业名单、简历与面试指导。支持关键词检索、来源角标/机构/文号查看、复制官方链接、☆ 收藏；未登录也可本地检索。

### 4.9 我的收藏

路径：我的 → 我的收藏。查看收藏的政策/渠道/指导资源，可取消收藏、复制官方链接、AI 提问；未登录时保存本机，登录后同步账号。

### 4.10 个人中心

我的页包含：我的关注/粉丝、我的收藏、功能说明、联系我们、会员入口。功能说明页内置本作品的完整使用说明书。

## 五、有效测试方式（评审可操作）

### 5.1 推荐验收路径（约 10 分钟）

| 步骤 | 操作 | 预期结果 |
|---|---|---|

| 4 | 点击星球 | 弹出该项得分、等级与一句话说明 |
| 5 | 首页 → 岗位招聘 → 选择岗位 → 岗位画像 | 十维要求 + 技能/证书清单 + 解析来源标注 |
| 6 | 查看岗位匹配 | 匹配度、类目得分、十维差距、缺口与建议 |
| 7 | 能力画像 → 生涯发展报告 | 五部分内容完整，任务可勾选并保留 |
| 8 | 首页 → 就业政策与校招资源 | 搜索、来源角标、复制链接、☆ 收藏可用 |

### 5.2 边界与异常验证点

- 能力画像信息不足：仅填少量信息时，结果标注信息不足/置信度较低，不给出误导性高分；
- 岗位信息不足：选择原文信息极少的岗位，匹配度应封顶并出现「岗位要求信息不足」提示（不会显示 100%）；
- 空数据：未建知识库、无收藏、无历史报告时显示空状态引导；
- 断网/后端未启动：联网功能给出失败提示并降级为本地规则解析（画像类），页面不崩溃。

## 六、常见问题

**Q1：扫官方小程序码看到的页面和说明不一致？**
A：线上版本仍是最初架构版本，尚未随迭代更新。请按 2.2 的方式体验当前版本（开发者工具 / 体验版）。

**Q2：登录失败怎么办？**
A：确认后端服务在运行、网络可达；账号密码正确。若提示网络异常，检查后端地址（开发者工具为 localhost，真机需改为局域网 IP）。

**Q3：点击生成画像一直转圈？**
A：AI 解析依赖后端任务队列（Celery）。后端服务未启动或队列未运行时任务只会排队；请联系团队启动后端后重试（前端超时约 90 秒后提示原因）。

**Q4：图片不显示？**
A：图标资源托管在图片 CDN 上，检查网络是否可访问 `youupro.xyz`；开发者工具可勾选"不校验合法域名"排查。

**Q5：编辑器里加粗后调字号没反应？**
A：微信 `editor` 组件每次格式操作后会清空选区，这是组件限制。请每次只设置一种格式，需要设置第二种时重新选中文字即可。
