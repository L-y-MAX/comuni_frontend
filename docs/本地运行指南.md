# 职引星途 · 本地运行指南（拿到源码的人看这份）

> 本文档面向：拿到本项目**前端 + 后端源码压缩包**的同学/评审老师。
> 目标：在你自己的 Windows 电脑上把前后端跑起来，用微信开发者工具打开小程序并完成联调。
> 全程约 40~60 分钟（首次装依赖较久）。

---

## 〇、你会收到的两个目录

| 目录 | 内容 | 说明 |
|---|---|---|
| `comuni_frontend` | uni-app（Vue3 + TS）小程序源码 | 不含 `node_modules` 和 `dist`，需要自己安装与构建 |
| `comuni_bakcend` | Django 后端源码（含 `.env` 配置） | 不含 `.venv`，需要自己创建虚拟环境装依赖 |

> 注意：如果压缩包里没有 `.env`，说明对方为了安全没带密钥，你需要按第 2.2 节自己填。

---

## 一、安装运行环境（一次性）

| 软件 | 版本要求 | 用途 | 安装方式 |
|---|---|---|---|
| Node.js | 18+（推荐 20/24） | 前端构建 | https://nodejs.org 装 LTS |
| pnpm | 10.x | 前端包管理 | `npm i -g pnpm` |
| Python | **3.12（必须）** | 后端运行 | https://www.python.org/downloads/release/python-3129/ （勾选 Add to PATH） |
| PostgreSQL | 18（16+ 也可） | 数据库 | https://www.postgresql.org/download/windows/ |
| Redis | 8.x（Windows 版） | 缓存 / Celery 队列 | 见 1.1 |
| 微信开发者工具 | 稳定版 2.02+ | 打开小程序 | https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html |

> ⚠️ **Python 必须是 3.12**：项目依赖 Django 5.2，不支持 3.14；用 3.13 也可能有兼容问题。装完在命令行执行 `python --version` 确认是 3.12.x。

### 1.1 Windows 上安装 Redis

任选一种：

1. **推荐**：下载 Windows 版 Redis（tporadowski/redis 的 release，zip 解压即用）：
   https://github.com/tporadowski/redis/releases
   解压后在该目录执行 `redis-server.exe redis.windows.conf`；
2. 或用 Chocolatey：`choco install redis-64`；
3. 或用 WSL 跑 `redis-server`（较麻烦）。

启动后执行 `redis-cli ping` 返回 `PONG` 即成功。

## 二、后端启动（Django）

### 2.1 创建数据库

打开 PostgreSQL 的命令行（psql）或 pgAdmin，用 postgres 超级用户执行：

```sql
CREATE DATABASE comuni;
CREATE USER comuni_user WITH PASSWORD '改成你自己的密码';
ALTER ROLE comuni_user SET client_encoding TO 'utf8';
GRANT ALL PRIVILEGES ON DATABASE comuni TO comuni_user;
```

### 2.2 配置 `.env`（关键）

后端根目录 `comuni_bakcend/.env`，按下面模板填写（如果压缩包已带 `.env`，只需核对数据库/Redis 密码）：

```ini
# ---------- Django ----------
SECRET_KEY=任意一串随机长字符串
DEBUG=True
ALLOWED_HOSTS=127.0.0.1,localhost
CSRF_TRUSTED_ORIGINS=http://127.0.0.1:8000,http://localhost:8000

# ---------- 数据库（与 2.1 一致） ----------
POSTGRESQL_NAME=comuni
POSTGRESQL_USER=comuni_user
POSTGRESQL_PASSWORD=你设置的密码
POSTGRESQL_HOST=127.0.0.1
POSTGRESQL_PORT=5432

# ---------- Redis / Celery ----------
REDIS_URL=redis://127.0.0.1:6379/1
REDIS_PASSWORD=你的Redis密码（没设密码就留空）
CELERY_BROKER_URL=redis://127.0.0.1:6379/1
CELERY_RESULT_BACKEND=redis://127.0.0.1:6379/1

# ---------- AI（能力画像/岗位画像/AI 问答要用） ----------
DEEPSEEK_API_KEY=你的DeepSeek密钥（没有可留空，AI 功能会降级为本地规则解析）
DEEPSEEK_API_URL=https://api.deepseek.com/chat/completions
DEEPSEEK_MODEL=deepseek-chat

# ---------- 小程序（非必需） ----------
APP_ID=
APP_SECRET=
```

> 说明：`.env` 从**项目根目录**读取，务必放在 `comuni_bakcend/` 下；`ALLOWED_HOSTS` 必须包含你访问用的地址（127.0.0.1 / localhost / 局域网 IP）。

### 2.3 安装依赖并初始化

在 `comuni_bakcend` 目录打开 PowerShell：

```powershell
python -m venv .venv
.\.venv\Scripts\activate
pip install --upgrade pip wheel
pip install -r requirements.txt
```

> 依赖较多（含 chromadb 等），首次安装约 5~15 分钟；建议内存 8G 以上，或先关掉其他大程序。如果下载慢，可加国内镜像：
> `pip install -r requirements.txt -i https://mirrors.aliyun.com/pypi/simple/`

初始化数据库与静态文件：

```powershell
python manage.py migrate
python manage.py collectstatic --noinput
python manage.py createsuperuser   # 可选：创建管理后台账号
```

> 如果需要演示账号：可以注册一个普通账号（小程序内注册），或用 Django shell 创建。

### 2.4 启动两个服务（必须都启动！）

**窗口一：Django**

```powershell
cd comuni_bakcend
.\.venv\Scripts\activate
python manage.py runserver 8000
```

**窗口二：Celery（画像解析/AI 问答靠它，Windows 必须 --pool=solo）**

```powershell
cd comuni_bakcend
.\.venv\Scripts\activate
python -m celery -A celery_config worker -l info --pool=solo
```

验证后端是否正常：

- 浏览器打开 http://localhost:8000/admin/ ，能出现 Django 登录页即成功；
- 或 PowerShell 执行：
  ```powershell
  curl.exe -s -o NUL -w "%{http_code}" http://localhost:8000/api/v1/knowledge/knowledgebase/my-knowledge-bases/
  ```
  返回 `401`（未登录）说明接口正常。

> 项目也提供了 `start_backend.bat`（自动拉起 Redis + Django + Celery），熟悉后可以直接双击运行。

## 三、前端启动（uni-app 小程序）

### 3.1 安装依赖并构建

在 `comuni_frontend` 目录：

```powershell
npm i -g pnpm        # 如果还没有 pnpm
pnpm install
pnpm dev:mp-weixin   # 开发模式（监听改动，产物在 dist/dev/mp-weixin）
# 或生产构建：pnpm build:mp-weixin（产物在 dist/build/mp-weixin）
```

> `dev:mp-weixin` 是常驻监听进程，改代码会自动重新编译；改完代码要重启后再到开发者工具点「编译」。

### 3.2 用微信开发者工具打开

1. 打开微信开发者工具 → **导入项目**；
2. 目录选择：`comuni_frontend\dist\dev\mp-weixin`（或 `dist\build\mp-weixin`）；
3. AppID：可用自己的小程序 AppID，或选「测试号」；
4. 导入后点「编译」；
5. 进入「详情 → 本地设置」，勾选：
   - **不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书**
   - 建议同时勾选「不校验 TLS 版本」相关项；
6. 出现首页即成功。

> 若菜单入口被胶囊遮挡或白屏：确认开发者工具版本 ≥2.02、基础库 3.17.x；必要时清缓存后重新编译。

### 3.3 接口地址确认

前端默认请求地址在 `src/utils/request.ts`：

```ts
const USE_LOCAL_API = true;
export const baseURL = USE_LOCAL_API ? 'http://localhost:8000' : 'https://你的域名';
```

- 后端跑在本机 8000 → 无需修改；
- 后端端口或地址不同 → 改 `baseURL` 后重新构建；
- 想用**真机**（手机）访问电脑上的后端：把 `baseURL` 改为电脑局域网 IP（如 `http://192.168.1.6:8000`），手机与电脑连同一 Wi-Fi，并确保防火墙放行 8000 端口；同时手机预览需在开发者工具中勾选"不校验合法域名"并开启调试模式。

## 五、常见问题

| 现象 | 原因 | 解决 |
|---|---|---|
| 启动报 `ModuleNotFoundError: No module named 'setsite'` | 没在项目根目录执行 | `cd comuni_bakcend` 后再执行 |
| 生成画像一直转圈后提示超时 | Celery 没启动 | 按 2.4 启动 worker；前端超时约 90 秒会提示原因 |
| 登录报 500 / 连不上 | 后端没启动、数据库连不上、`.env` 里 `ALLOWED_HOSTS` 不含地址 | 检查 `_runserver.err.log`、数据库账号密码、`.env` |
| Redis 相关报错 `AUTH failed` | `.env` 里的 Redis 密码与实际不一致 | 三处（REDIS_PASSWORD / CELERY_BROKER_URL / CELERY_RESULT_BACKEND）保持一致 |
| 图片不显示 | 图标托管在图片 CDN（youupro.xyz），网络不通或合法域名限制 | 开发者工具勾选"不校验合法域名"；检查网络能否打开 `https://youupro.xyz` |
| 真机连不上后端 | 真机访问不到电脑 localhost | 改 `baseURL` 为电脑局域网 IP，手机同网段、防火墙放行 |
| 编辑器加粗后再调字号没反应 | 微信 editor 组件每次格式操作后清空选区（组件限制） | 每次只设置一种格式，需要第二种时重新选中文字 |
| `pip install` 失败/卡住 | 网络或 Python 版本不对 | 用镜像源；确认 `python --version` 是 3.12 |

---

## 六、注意事项

1. **不要外传 `.env`**：里面有数据库密码、DeepSeek 密钥等；转交源码时建议改成占位模板；
2. 如果只需要看界面、不跑 AI 功能：DeepSeek Key 可以留空，画像会降级为本地规则解析（功能可用、精度下降）；
3. 前端 `dist/`、`node_modules/`、后端 `.venv/` 都不要打进压缩包（体积大且与本机环境绑定）；
4. 代码在持续迭代中：拉到的版本功能以实际代码为准，本指南随代码同步更新。
