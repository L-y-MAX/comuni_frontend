首页四张卡片的图标放在这个目录里，文件名必须完全一致（小写、无空格、无中文）：

  jobs.png        -> 首页「岗位招聘」
  policy.png      -> 首页「就业政策与校招资源」
  jobprofile.png  -> 首页「岗位能力画像」
  knowledge.png   -> 首页「知识库」

建议规格：
  - 格式：PNG（透明背景更好，因为卡片是白底）
  - 尺寸：正方形，建议 96x96 或 81x81（界面显示约 48rpx）
  - 大小：40KB 以内

注意：
  - 不要放到 dist/ 目录，那里每次构建都会被清空重建。
  - 文件名里的空格很容易被忽略，之前底部导航图标全部不显示就是这个原因。
  - 缺图不会报错：界面会自动退回 emoji 图标（依次为 🏢 📚 💼 📝）。
  - 放好图片后需要重新构建（npm run dev:mp-weixin）才会生效。
